## Problem
We needed to convert the existing search engine into an OpenAPI-based SaaS while handling different data standards across e-commerce platforms and rising traffic.

## Approach
We standardized the search EP schema, then designed the API contracts and operations back office around it. This improved reliability for clients and gave the service room to scale.

## Execution
- Documented EP file formats, naming conventions, and validation policies in a common standard
- Expanded the search API schema around the features clients used
- Added an admin screen to track onboarding and operations status
- Ran Scrum with AI Research, BE, Data Engineering, and Product Design

![E-commerce Search AIaaS screen](/assets/images/projects/buzzni/buzzni-search-aiaas-shot-01.webp)

## Results
- Delivered search services to 3 clients: 쇼핑엔티, SK스토아, and 어바웃펫
- Ran PoCs with 7 enterprises to expand the sales pipeline
- Standardized search data contracts to speed up onboarding for new clients
