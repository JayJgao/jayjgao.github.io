## 问题
现有搜索引擎需要转为基于 OpenAPI 的 SaaS。与此同时，我们还要处理不同电商平台的数据规范差异，并应对流量增长。

## 方案
我们先统一搜索 EP schema，再把 API 契约和运营后台一并纳入设计，兼顾客户侧的可靠性和扩展能力。

## 执行
- 将 EP 文件格式、命名规则和校验策略整理成标准文档
- 根据客户实际使用的功能扩展搜索 API schema
- 上线管理界面，用于查看接入进度和运营状态
- 与 AI Research、BE、Data Engineering 和 Product Design 团队以 Scrum 方式协作

![电商搜索 AIaaS 界面](/assets/images/projects/buzzni/buzzni-search-aiaas-shot-01.webp)

## 结果
- 完成 3 家客户的搜索服务交付（쇼핑엔티、SK스토아、어바웃펫）
- 为 7 家企业运行 PoC，扩大销售管线
- 统一搜索数据契约，加快新客户接入
